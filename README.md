# 游泳赛事泳道电子计时复核系统

比赛现场计时器漏记或成绩争议时，裁判结合**电子原始读数**与**手工记录**作出复核，总裁判终局裁定采用电子成绩 / 手动成绩 / 重赛结果；公示榜单按版本发布，标注更正时间与原因，旧榜单和原始读数永久可查。

- 后端：Go 1.22+ / Gin / GORM / SQLite（纯 Go 驱动，无需 CGO）
- 前端：Vue 3 + Vite（构建后由 Go 同端口托管）
- 电子计时设备：内置**本地模拟接口**（正常 / 漏记 / 部分分段 / 并列 / 补发 / 重赛报文）

## 一条命令启动

```bash
./run.sh          # 首次会自动安装依赖、构建前端并在 :8080 启动
```

打开 http://localhost:8080 ，演示账号（密码）：

| 岗位 | 账号 | 密码 | 权限 |
|---|---|---|---|
| 录入员 | `clerk` | `clerk123` | 从设备导入读数（追加批次）、请求设备补发、补充文字材料；**不能改变名次** |
| 裁判 | `judge` | `judge123` | 提交手记触壁时间与说明、发起漏记/争议/并列复核 |
| 总裁判 | `chief` | `chief123` | 终局裁定（电子/手动/重赛）、撤回、发布与更正榜单 |

其他命令：`./run.sh dev`（前端热更新 :5173）、`./run.sh reset`（清空数据库重来）。

## 演示场景

种子数据含两个项目，设备报文设计了典型争议：

- **M101 男子100米自由泳决赛**：3 道触板**漏记**（仅 50m 分段）；5、6 道电子成绩同为 55.32 **并列**。
- **M102 女子200米蛙泳预赛**：2 道电子与手记存在出入（争议）；4 道仅部分分段；1、6 道并列。

### 漏记复核流程（M101）
1. `clerk` 登录 → 「从计时设备导入读数」→ 3 道显示 MISSED、无成绩、榜单无法发布。
2. `judge` 打开 3 道：提交手记 55.67 与说明 → 发起「计时器漏记」复核。
3. 路径 A：`chief` 裁定「采用手动成绩」并填写依据 → 3 道以 55.67 计第 4 名 → 发布榜单。
4. 路径 B（设备恢复）：`clerk` 点「设备补发」填入 55.67 → 重新导入生成**第 2 批次**；第 1 批漏记报文仍可在「查看全部历史批次」中查到。

### 并列与重赛（M101）
1. 导入后 5、6 道并列第 2 名（标准竞赛排名 **1-2-2-4**），均标 `并列`。
2. `judge` 在「并列情况」发起复核；`chief` 裁定重赛 → 左侧自动生成 **M101-SO1（重赛）** 项目。
3. 进入重赛项目，`clerk` 导入设备的重赛报文（55.14 / 55.48）。
4. 回到 M101：两道改标「重赛成绩」并分出先后；`chief` 填写更正原因发布第 2 版榜单。

### 撤回
`chief` 对任一泳道执行「撤回」并填写原因 → 榜单保留该泳道、标记「撤回」、不排名次。

## 数据与审计规则

- **原始读数不可变**：每次导入是一个新批次（`import_batch` 递增），任何更正都新增数据，不 UPDATE/DELETE 旧读数。
- **榜单是快照**：发布生成 `boards + board_entries` 版本；新版发布时旧版仅置 `SUPERSEDED`，内容永不变。更正发布**必须填写原因**，榜单页展示更正时间、原因、发布人，可逐版回溯。
- **裁定只追加**：`review_cases` + `rulings` 记录复核链路、结论与依据，全部操作写入 `audit_logs`。
- **录入员隔离**：其手记成绩字段在服务端直接拒绝（403），只有裁判/总裁判的手记可被裁定采用。

## API 摘要

| 方法 | 路径 | 岗位 |
---|---|---
| POST | `/api/auth/login` | 公开 |
| GET | `/api/races/:id` / `/readings` / `/boards`，`/api/boards/:id` | 已登录 |
| GET | `/api/device/sessions` | 已登录 |
| POST | `/api/races/:id/readings/import` | 录入员 |
| POST | `/api/device/sessions/:code/retransmit` | 录入员 |
| POST | `/api/races/:id/lanes/:laneId/notes` | 已登录（录入员禁带成绩） |
| POST | `/api/races/:id/cases` | 裁判 / 总裁判 |
| POST | `/api/cases/:id/rulings` | 总裁判 |
| POST | `/api/races/:id/lanes/:laneId/withdraw` | 总裁判 |
| POST | `/api/races/:id/boards` | 总裁判（更正需带原因） |
